# vokabeltrainer-content

Dieses Repository enthält nur von der App importierbare Vokabeldaten.

## Struktur
- `manifest.json` beschreibt Sprachen, Bücher und Seiten.
- Jede Seite ist eine eigene JSON-Datei mit `page` und `vocabulary`.
